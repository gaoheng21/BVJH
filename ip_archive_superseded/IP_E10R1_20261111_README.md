# IP_E10R1_20261111 — Controlled BadMagic Counterfactual Interaction Study

## Purpose

First mechanistic experiment **after** frozen E8R1: a known-trigger BadMagic insertion/removal study. It does **not** tune an E8 threshold, modify model weights, claim universal causal identification, or produce new F1/ASR estimates for a detector. Uses only the existing backdoored Llama-2-7B-Chat + BadNet LoRA model (no clean base comparator).

## Placement and running

Unpack this ZIP directly in the BV repository root, e.g. `/science/gh/Backdoor-Vaccine`, where `IP_E8R1_20261111_e4_primitives.py` and `data/` already exist. This ZIP has only uniquely named E10 files; **does not include or replace** E8.

```bash
cd /science/gh/Backdoor-Vaccine
unzip IP_E10R1_20261111_counterfactual_package.zip
conda activate crow
CUDA_VISIBLE_DEVICES=0 bash IP_E10R1_20261111_run.sh
```

The launch script checks SHA-256, runs CPU-only unit tests, performs data/model-path preflight, allocates a **new** `outputs/interactionprism/e10_runs/E10R1_<timestamp>_<pid>/` directory, and launches the CUDA study. It refuses to overwrite nonempty result directories.

If GPU memory is tight, run the same command with `--batch-size 1` after the shell script name. Optionally use `--n-contexts 8 --n-poison 6` for a smoke test in **its own** fresh run, then run the default full experiment separately. The default is 24 clean contexts, 16 poison samples, batch size 2 and 48 generated tokens. It does forward passes and autoregressive generations, so **GPU is required**.

## Protocol

1. Reconstruct E8's frozen 130-prompt center: 30 poisoned train + 100 clean train instructions, `\nAnswer:` readout, hidden state index `-1`.
2. Use 24 **hand-authored** clean reference instructions in the included JSON, enforcing no exact normalized overlap with all four BV training/test JSON datasets. This rules out exact duplicates, not all semantic overlap. The clean contexts are not drawn from E8's heldout set.
3. Insert `BadMagic` after the first word of each clean context. At the **same position**, insert `thing` (neutral), `garden` (ordinary), and a preselected nonce word (rare-word **proxy**; code attempts to match the insertion-token count but does not claim frequency matching). Check and record tokenizer token counts.
4. For each pair, compute last-layer `z(c+word) - z(c)` using the **same backdoored model** and fixed Answer suffix. Report norms, normalized directional coherence and bootstrap descriptive intervals.
5. As a *mechanism-only probe for this known BadNet experiment*, measure teacher-forced `log P("\nYou are stupid!" | BOS + instruction + "\nAnswer:")` and its change. This **must not** be incorporated into a generic unknown-attack detector.
6. Generate with greedy decoding under **raw BOS+instruction**, without the Answer suffix, following the BV `eval_asr.py` input protocol; measure keyword-hit changes as an *exploratory behavioral indicator*. The distinct readout/generation prompt protocols are recorded transparently.
7. Select 16 eligible single-BadMagic cases from the **first 200** E8 heldout poisoned test examples, remove only the exact character span of `BadMagic` (removing one of two adjacent spaces), and also replace it with `thing` as a perturbation control. Compare original vs removal and neutralization, including direction alignment with clean-context insertion deltas. Multiple occurrences are excluded to avoid ambiguous removals.

**Important**: The E8 heldout poisoned samples are reused strictly to understand mechanisms, not for optimizing or re-evaluating the formal E8 detector. This first study uses the *known* trigger only for controlled mechanism tests. A later E10 version may use the E8 automatically extracted winning player; it is **not implemented** in this first study.

## Output files

- `console.log`: full run log
- `manifest.json`: paths, token counts, checksum and data protocol
- `summary.json`: aggregate magnitude, coherence, log probabilities, alignments, raw output indicators and descriptive bootstrap intervals
- `report.md`: human-readable first-round table and limitations
- `clean_insertions.jsonl`: each original/insertion pair, changes, outputs
- `poison_removals.jsonl`: exact location of removed trigger, removal/control changes, alignments, outputs
- `run_manifest.txt` / `runner_sha256.txt`: run provenance

Please return `report.md`, `summary.json`, `clean_insertions.jsonl`, `poison_removals.jsonl`, and `console.log` (or zip the full run directory). We will check whether trigger insertion is distinct from the controls, whether induced change directions transfer, and whether output behavior follows the same direction; we will **not** claim proof from hidden-state magnitude alone.

## Technical notes

- Frozen E8 primitives are imported at runtime and hashed. **Do not edit** `IP_E8R1_20261111_e4_primitives.py`.
- E8 readout is a fixed 4-token suffix under the project's Llama-2 tokenizer; execution fails if that protocol differs.
- No training, weights writes, quantization, new detection threshold, model purification, or access to clean base model.
- Candidate insertion and removal are interventions on **input text**. A large effect is an operational observation, not a general causal theorem.
- Experiments are run in the user GPU environment; the authoring environment only ran CPU unit tests and syntax checks.
