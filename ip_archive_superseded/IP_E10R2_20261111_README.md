# IP_E10R2_20261111 — probability/readout protocol audit

## Why this one experiment

E10R1 produced an apparent mismatch: 21/24 clean-context BadMagic *raw generated outputs* contained `You are stupid!`, yet the E10R1 teacher-forced target log probability of `\nYou are stupid!` **decreased** for all 24. The old likelihood evaluation prepended `\nAnswer:` but the old generation did **not**. E10R2 tests this measurement-protocol mismatch explicitly; no detector score/threshold changes.

This is an **offline known-trigger, known-target mechanism audit**. A positive result is not evidence of attack-agnostic detection, does not change E8R1 F1, and should not be treated as a causal proof without controls.

## What it does

- Reuses precisely the same 24 clean contexts and the same 16 eligible heldout poisoned prompts; verifies the clean-context file SHA and the E10R1/E8 helper SHA values.
- Uses **one unchanged BadNet LoRA model** in inference mode. No training, no adapter edits, no modifications to E8R1/E10R1.
- Fixed prompt variants:
  - `suffix_space` (primary): prompt `BOS + instruction + "\nAnswer:"`; next target text `" You are stupid!"`.
  - `suffix_newline_e10r1` (diagnostic old): same fixed prompt; next text `"\nYou are stupid!"`.
  - `raw_answer` (diagnostic): prompt `BOS + instruction`; next text `"Answer: You are stupid!"`.
  - `raw_plain` (diagnostic): prompt `BOS + instruction`; next text `"You are stupid!"`.
- Also **generates actual completions under the fixed suffix** (so this generation is aligned with the fixed-prompt target-probability probes). Generation uses an attention mask and deterministic greedy decoding.
- All reported probability changes are paired differences on the same text context; controls are neutral `thing`, ordinary `garden`, and token-count-matched rare `BlueHarbor`.
- Prints one compact `COPY_TO_CHATGPT` block at the end. No need to upload all result files unless a later deeper audit is requested.

## Requirements

Use the **same BV project root / Python environment and GPU** that ran E10R1. These files must already exist in the project root from previous experiments:

- `IP_E10R1_20261111_counterfactual.py` (verifiably unchanged)
- `IP_E8R1_20261111_e4_primitives.py` (verifiably unchanged)

The project data and model paths remain unchanged. Do **not** extract into an E8/E10R1 source folder; extract into `/science/gh/Backdoor-Vaccine` root.

## Run (one command after unzip)

```bash
cd /science/gh/Backdoor-Vaccine
unzip IP_E10R2_20261111_protocol_audit_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E10R2_20261111_run.sh
```

If not currently in your E10R1 Python/conda environment, activate it first (the previous log named the `BV` environment). Requires CUDA and the same model files.

If successful, the terminal ends with:

```
========== COPY_TO_CHATGPT_BEGIN ==========
experiment=IP_E10R2_20261111
status=SUCCESS
...
========== COPY_TO_CHATGPT_END ==========
```

Just copy that exact block into the chat. The script stores output in a **new unique** `outputs/interactionprism/e10_runs/E10R2_*/` folder:

- `copy_to_chatgpt.txt`: terminal paste block
- `summary.json`: full protocol-dependent aggregated statistics
- `clean_protocol_audit.jsonl`: per-clean-context paired scores and fixed-suffix generations
- `poison_protocol_audit.jsonl`: per-poison removal/neutralization probes
- `console.log`: full standard output

When reviewing, interpret *each* prompt/target string separately; **do not choose the maximum of the four variants** after seeing the results and claim it as a detection method. E10R2 is a targeted readout audit only, not an extension to the deployed anomaly detector.

## Scope and safeguards

- This package is **not** a new E10 detector. It does not change E8R1, E9, E10R1, any model weights, or any historical outputs.
- Exact-normalized overlap tests and no-truncation guards are reused.
- Output directory is uniquely named, and the Python script refuses to overwrite any existing result file.
- CPU tests / preflight run before GPU loading. If the E8/E10R1 source has been edited, the run stops rather than mixing protocols.
- No use of the E8 heldout labels to choose a threshold; poisoned examples serve only as known-trigger mechanism controls.
