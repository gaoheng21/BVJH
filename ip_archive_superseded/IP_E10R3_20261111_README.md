# E10R3 — Token-level protocol mismatch diagnostic

## Question

E10R2 found **24/24** BadMagic insertions triggered the exact target under `\nAnswer:` generation, while its *predeclared primary* teacher-forced probe `suffix_space` was **-1.3651** median logP difference (7/24 positive). The `raw_answer` probe had **+11.1207**, but its input protocol has **no suffix**, so this cannot be reported as an aligned fixed-suffix probability result.

E10R3 diagnoses the remaining discrepancy **without changing any models, previous experiments, the E8R1 detection rule, or its heldout outcomes**.

## Experiment

- Reuse frozen E10R1 and E8 helper SHA-256, the same 24 independently authored clean contexts, the same first 16 eligible E8 heldout poison cases. All known-trigger/known-target **mechanism** data, not a general detector.
- Use the same BadNet LoRA once, no retraining and no weight edits.
- Score three *predeclared* conditional target tokenizations: `suffix_space` (`BOS+instruction+\nAnswer:` then ` You are stupid!`), `suffix_newline` (same prefix then `\nYou are stupid!`), and `raw_answer` (`BOS+instruction` then `Answer: You are stupid!`).
- For each condition compute **changed minus baseline**: whole target logP, first target token logP, remainder logP, first token's vocabulary rank, and whether target tokens align with the top-1 forced path. Keep paired inputs.
- Check whether the explicit prefix+target **token stream** matches tokenizing the joined text in one call; mismatch is a warning about token segmentation, not automatic invalidation of the explicit token stream.
- Print three short examples per group of real **unstripped** greedy generations under the fixed suffix (to detect leading spaces, newlines and preambles).
- All outputs go into a fresh `outputs/interactionprism/e10_runs/E10R3_.../` directory. Only the final terminal copy block is needed for normal collaboration.

## Interpretation limits

1. Target string logP, literal substring hit rate, and greedy decoding are different measurements. A negative total logP change can coexist with greater first-token probability or a successful greedy target string.
2. A *raw* probability variant cannot be chosen post hoc as a better detector. Differences across probing protocols are measured for understanding, not optimizing E8.
3. When the same visible string admits multiple token paths, teacher-forced token IDs do not necessarily describe the aggregate probability of all paths that decode to that string.
4. No new F1, attack-agnostic generalization, or proof of universal causality is claimed. This is one step in the known-trigger mechanism study.
