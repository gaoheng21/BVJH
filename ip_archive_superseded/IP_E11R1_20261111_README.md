# IP_E11R1_20261111 · 自动玩家提取与反事实验证（离线机制诊断）

## 本轮的科学问题

已冻结的 E8R1 检测器输出某个样本最强的 singleton 玩家 `winning_word`。E11R1 不预先指定 `BadMagic` 或任何攻击目标回答，而是**从冻结 E8 运行记录自动提取玩家**，在同一 BadNet LoRA 模型上进行配对插入、移除及文本输出变化观察，并比较 E8 的 TP、FP、FN、TN。

**此轮不是新的检测器。** 已知标签仅用于分组选样和事后离线对比；不以标签训练、调权重、拟阈值，也不声称新的 F1、FPR、未知攻击泛化或因果证明。

## 环境和输入

- 在 `/science/gh/Backdoor-Vaccine` 项目根目录运行。
- 本机需要已有的 CUDA GPU、Python 环境（`BV`）、`torch`、`transformers`、`peft`、`numpy`。
- 需要冻结的 `IP_E8R1_20261111_e4_primitives.py` 和历史 `E8R1` 运行目录，其中含 `summary.json` 与 `heldout_records.json`。
- E8 代码及四个数据 JSON 必须与 E8 当年的 `summary.json` 记录的 SHA-256 哈希一致。**不提供覆盖/绕过开关**。
- 需要一个 fast tokenizer 用于精确的原始字符 offset。定位失败、玩家跨多词或文本会截断时，**跳过并记录原因**。
- 附带 16 条全新干净指令，程序先确认与 E8 四个 JSON 按空白归一化后不重叠；每个候选默认取 8 条。来源独立于 E8，但并非新的随机人口样本。

## 服务器运行（三行）

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E11R1_20261111_auto_counterfactual_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E11R1_20261111_run.sh
```

如有多个 E8R1 历史运行目录，自动发现无法唯一判定时，可明确指定（**注意此参数应是包含 summary.json 的目录**）：

```bash
E8_RUN=outputs/interactionprism/e8_runs/E8R1_20261111_082944_1039497 CUDA_VISIBLE_DEVICES=0 bash IP_E11R1_20261111_run.sh
```

每次运行都创建唯一目录：

`outputs/interactionprism/e11_runs/E11R1_YYYYMMDD_HHMMSS_.../`

不会覆盖 E8R1/E9/E10 文件或先前 E11 的实验输出。

## 具体计算

1. 读取**已保存**的 E8 记录（并核对其文件哈希和冻结阈值）。从样本的 `singleton_abs` 取 argmax，定位 `winning_word`。
2. 在同一模型上重复 E8 的词级筛选，要求整个 Top-6 原样匹配，然后通过 fast tokenizer `offset_mapping` 恢复胜出玩家的精确字符位置。如果玩家多词粘连、定位歧义、截断或候选池不一致，则跳过并报告。
3. 原样保留当前模型、`\nAnswer:` 四 token 读取协议和最后一层表征；分别计算插入前后、移除前后与中性替换前后的隐藏状态差异。差分中同一个 E8 参考中心会相消，即 `Δ(h − hbar) = Δh`，不必重复求其均值。
4. 插入玩家到 8 条干净指令，使用 `thing`、`garden`、罕见词作同位置对照；罕见词仅在确实 token 数匹配时标记 `rare_token_count_matched=true`，不伪称全部匹配。
5. 计算插入偏移二范数、跨上下文方向一致性、与原样本移除向量的余弦对齐、相对于普通词的配对差异。
6. 用没有预设目标字符串的原始 BOS+instruction 贪心生成，对原始/删除/中性替换及少量独立参考插入做简单文本变化描述。**文本变化幅度不是后门目标行为成功率，更不是新检测器得分。**
7. 将结果按 E8 历史标签事后分成 TP/FP/FN/TN，小规模观察信号是否存在差异，不在这批样本上调 E11 融合阈值。

默认最多抽取 TP=8、FP=4、FN=4、TN=4；因玩家定位失败可能略少。选样基于 E8 分数与已有标签，不使用 E11 结果来挑好看的例子。只有 TP 和 FP 都至少有 2 条可正确定位才标记研究成功。

## 界限

- 初步已知 BadNet 机制实验 E10R1-R3 与这个**自动玩家实验**性质不同，不能把已知 BadMagic 的命中率转移为 E11 通用性能。
- `E8R1` 正式检测阈值保持原值，不修改 E8 源码；未构造新的最终“正常/后门/待验证”分类器。
- E8 原本玩家构建存在少量跨空白粘连，本实验**只对干预定位做保守拒绝**，不修改冻结检测器。
- GPU 实跑尚未在交付环境完成。CPU 单测只是接口、字符串处理、边界检查，不替代真实 GPU 整合测试。
