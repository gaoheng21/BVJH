# InteractionPrism E11R3：全 400 条样本自动玩家与反事实交互结构审计

## 目的与范围

本包在 BV 根目录运行，复用**冻结的 E8R1** 的 400 条 heldout 记录（前 200 条真实中毒、后 200 条真实干净），不重训模型、不修改任何 E8 文件、不重新校准阈值。E8 原始检测结果保持 `Score = |I1|_(1) - |I1|_(2)` 和 `threshold = 0.237005`。仅对 E8 保存的疑似主导玩家进行后续反事实验证，并附加**新计算的二阶 Harsanyi 诊断**。本次不是新的正式检测器、不在测试标签上设计/调参融合阈值、不声称性能提升。

**本项目中的“异常交互结构”应准确区分：**

- E8 存档的 6 个单玩家绝对贡献 `|I1(w)|`：**E8 原始正式特征**；CSV 中 `e8_top6_singleton_structure_json`。E8 未保存这些一阶项的符号，不能凭空补符号。
- E11R3 根据冻结 E8 Top-6 玩家，使用同一个 `\nAnswer:`、同模型、同原始 130 条训练来源混合参考中心重新计算的 `I1` **带符号**值及全部 15 个 `I2(wi,wj)` **带符号**值：**额外机制诊断，不属于 E8 正式检测器**；CSV 中 `recomputed_signed_I1_json` 与 `second_order_Harsanyi_pairs_json`。
- `I2(wi,wj) = v({wi,wj})-v({wi})-v({wj})+v(∅)`。I2 的数值或正负不等于证明 AND 型因果机制、也不能直接说明攻击成功。
- Stage 2 使用独立的 16 条人工参考指令中的 8 条（每个玩家过滤含该玩家的上下文）进行 **同模型插入**，并在原始输入上精确移除/替换**自动定位**的玩家，比较隐藏层偏移、跨上下文方向一致性、方向对齐和中性/普通/罕见词对照。
- BadMagic / 目标回答不出现在推理选择或验证逻辑中；真实中毒标签只用于**结果导出和 TP/FP/FN/TN 分组**。

## 安装与运行

把 ZIP 放在已同步的仓库根目录后：

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E11R3_20261111_fullset_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E11R3_20261111_run.sh
```

这是完整数据集的 GPU 推理工作，**需要 Llama-2-7B-Chat 和 BadNet LoRA 所在的服务器环境**。脚本先核验打包文件的 SHA-256、执行 CPU 回归测试，再校验 E8 summary/records 与 E8 helper、4 个数据集的冻结哈希。否则立即停止。

默认计算所有 400 条样本的一阶归档与二阶交互结构，以及能安全定位的样本的 8-上下文反事实隐藏层指标。默认**不生成回答文本**，避免把“文本不同”错当成后门攻击成功；如明确需要 400 条原始/移除生成，可用 `E11_GENERATE=1`，但将大幅增加 GPU 工作量。没有生成时 CSV 的生成字段为空。

### 输出文件（新目录，不覆盖历史）

`outputs/interactionprism/e11_runs/E11R3_日期时间_随机标识/`

**优先查看以下文件：**

1. `all_400_samples_interaction_audit.csv`：400 条独立样本，一条一行，含真实标签、E8 预测、候选玩家、词级位置、Top6 一阶结构、二阶所有 15 个双玩家贡献、反事实指标、原始文本、跳过原因。可用 Excel/LibreOffice 打开，UTF-8 with BOM 编码。
2. `poisoned_200_samples_interaction_audit.csv`：单独输出的 **200 条真实中毒样本** 明细，字段与上面相同，来源于 heldout 数据真实标签，**不是算法认为的中毒样本**。
3. `all_400_samples_interaction_audit.jsonl`：机器可读完整结构，每个样本一行，包括每个参考指令的反事实证据；运行时逐行持久化，支持中断后恢复。
4. `summary.json`, `report.md`, `copy_to_chatgpt.txt`, `console.log`, `manifest.json`：按实验用途查看的汇总、日志、签名和可复制结果。

CSV 的重要字段：

| 字段 | 含义 |
|---|---|
| `true_label` | 真实标签：1=中毒，0=干净（仅离线研究） |
| `e8_prediction` | 冻结 E8 输出：1=可疑，0=未检出 |
| `cohort` | TP、FP、FN、TN，根据上述标签和 E8 输出派生 |
| `e8_score`, `e8_cutoff` | E8 存档 Top1-Gap 和冻结阈值 |
| `e8_winning_word`, `selected_player_raw` | E8 主导玩家、精确定位恢复的原文玩家 |
| `char_start`, `char_end`, `localization_method` | 原文位置，是否与 E8 Top-6 完全一致；无法唯一定位时拒绝干预 |
| `e8_top6_singleton_structure_json` | E8 Top-6 玩家和存档的单玩家贡献绝对值 |
| `recomputed_signed_I1_json` | 新重算的带符号一阶贡献，区别于历史 E8 存档 |
| `second_order_Harsanyi_pairs_json` | 新增的最多 15 个二阶组合及其带符号贡献 |
| `max_abs_I2_pair`, `max_abs_I2` | 二阶绝对值最大的联盟和大小，非新判定分数 |
| `insert_candidate_norm`, `candidate_minus_neutral` | 把候选词插到干净参考指令后的表征偏移及中性词对照差值 |
| `candidate_coherence` | 多个干净上下文插入偏移方向一致性 |
| `remove_insert_alignment` | 原样本移除向量与参考上下文插入向量余弦相似度中位数 |
| `stage2_status`, `stage2_error`, `pairwise_status` | 完成/未完成原因，避免静默漏样本 |
| `generation_status` | 默认 `not_measured`；并非“未触发后门” |

### 已知限制

- 每条样本都有导出记录；部分玩家可能因跨空白边界、重复词而无法安全定位、候选池数值漂移、长度导致截断风险或控制文本无效，被标记为跳过。**400 行导出不意味着 400 条均成功完成 GPU 验证**。总结中会明确 `stage2_ok` 数量和跳过原因。
- 冻结 E8 归档中只有单玩家贡献绝对值；二阶数字来自新前向计算，单例重算与 E8 存档的最大偏差也写入 CSV。若粗筛池与 E8 不一致，二阶比较标记不可用；仍可尝试在唯一词级 span 的安全条件下做反事实。
- 200 条中毒样本可能重复提取同一个候选玩家，例如同一个词。相同候选玩家的跨上下文插入证据被缓存，因此它们**不是 200 次独立触发器发现**。
- 同一 400 条 heldout 数据既用于 E8 正式评估，又在此被复用分析；不得在这批数据上调新融合阈值后宣称独立测试 F1。
- 只用当前 BadNet-LoRA 模型，不要求干净基座模型；默认输出隐藏层证据，没有外推到未知攻击或模型类型的验证。
- 二阶 Harsanyi 是固定 keep-only 游戏的非加性分解，不能代替交互因果检验。

## GPU 中断恢复

如果某次意外中断，新目录内的 `all_400_samples_interaction_audit.jsonl` 已经逐行存储已完成样本：

```bash
E11_RESUME_RUN='outputs/interactionprism/e11_runs/E11R3_刚才的目录名' CUDA_VISIBLE_DEVICES=0 bash IP_E11R3_20261111_run.sh
```

程序验证 E8 和关键实验参数未变化、已保存样本按 0..N-1 连续编号后，只补后续样本，不覆盖历史文件。若已跑完 400 条，不允许重复覆写。

## 包含文件

- `IP_E11R3_20261111_fullset.py` — 主实验脚本

- `IP_E11R3_20261111_checksums.sha256` — 所有上述文件的 SHA-256 检验

生成、打包环境只执行了语法/CPU/Shell/ZIP 检查，**不能代替你服务器上的 GPU 实验结果**。
