# InteractionPrism · E12R1：可变规模异常联盟全量实验

**版本：** `IP_E12R1_20261112`  
**用途：** 在**冻结 E8R1** 的 400 条 heldout 指令（200 中毒、200 干净）上，研究 **1、2、3 词玩家联盟** 的等效交互贡献、稳健离群、稀疏交互图和反事实验证。

本包**不是**新的正式检测器：不重训模型、不修改 E8 阈值 `0.237005`，不在 heldout 标签上调二阶段阈值，也不输出虚构的新 F1。仅使用同一个 BadNet-LoRA 模型；**候选发现与反事实验证阶段均不知道触发器文本、攻击目标或测试标签**。标签只在保存的离线审计文件中使用。

## 一条命令运行全部 400 条

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E12R1_20261112_variable_coalition_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E12R1_20261112_run.sh
```

运行环境：原 BV Python 环境（有 `torch`, `numpy`, `transformers`, `peft`, `tokenizers`），基座模型 `/home/gh/Llama-2-7b-chat-hf`，LoRA 为 `backdoor_weight/LLaMA2-7B-Chat/negsentiment/badnet`。**需要 GPU；按单张 A100 设置默认 batch_size=8**。包的 CPU 单测不需要 GPU。多次实验都会创建独立目录；历史 E8/E10/E11 文件不被修改。

运行前先校验本 ZIP 的 SHA-256、进行 CPU 单元测试、检查冻结 E8R1 的 summary、400 条 heldout records、辅助 Python 和四个数据文件的 SHA-256，以及参考指令与 E8 数据的精确规范化去重检查。不符合要求即停止。

### 全量探索的数学含义

玩家仍使用 E8 的 `tokenizer` 原生词级边界。价值函数保持 E8 的 `keep-only + thing 中性填充 + \nAnswer: 固定读取 + 同一混合训练参考中心`，模型隐藏层仍为 -1。

对一个联盟 `S`，记 `G(S)=v(S)-v(∅)`，`I(S)=Σ_{T⊆S}(-1)^{|S|-|T|}v(T)`。

- 一词：所有玩家 `I1`，并计算样本内部的 MAD 稳健离群分数。
- 二词：逐一扫描所有相邻二词、三词所需的隔一词配对，再从 **最多 12 个种子节点的稀疏交互图**中计算补充非相邻二词；记录有符号 `I2`、绝对 `I2`、整体效应 `G2`。
- 三词：**无条件**扫描所有相邻三词窗口（不要求其中任一单词已经离群），对全部子联盟进行精确 Möbius 反演，记录有符号 `I3`、整体效应 `G3` 和累计非加性 `G3 - ΣI1`。
- **重要：** 词组整体效应大，不等于高阶 AND 交互；负的 Harsanyi dividend 不等于模型后门被抑制。
- 搜索输出保留原始 **索引、字符偏移、原始词语、渠道、Harsanyi 符号及绝对值**。玩家存在跨空白、偏移歧义或超长时不会冒险删除。

### 候选校准与反事实

利用 E8 训练来源的 **400 条纯净校准指令** 中确定性选出的 48 条（`train_clean[100:500]`），为每个联盟规模/特征族统计**每条干净指令内的最大值**作为零参考分布。`I1, |I2|, |G2|, |I3|, |G3|` 分别校准，使用 MAD 标准化探索排序，并记录经验尾比例；这是探索性的排名参照，**不是经过独立试验确认的 FPR 控制或 p 值**。不同长度文本的最大值仍可能带来比较偏差，需后续研究。

每条输入默认选 4 组进入反事实：单词、连续二词、连续三词、图二词（若存在）。在 8 条与所有 E8 数据不重叠的干净参考指令上，将整个候选联盟插入；在原始输入上精确移除/中性替换相应玩家，计算：

1. 插入后的表征偏移强度、跨上下文方向一致性。
2. 原始移除的偏移方向与反事实插入的方向对齐。
3. 中性词、普通词、近似 token 数匹配的罕见词控制，并显式记录是否真正匹配。
4. **多词子集消融：** 对每个入选的 2/3 词联盟，在参考指令内额外插入所有非空真子集，计算“全联盟 vs 最强单词”偏移差，以及全联盟向量减去单玩家向量和的残差。它们是机制诊断，不可直接当作后门目标行为。

8 条参考上下文用于反事实，另外 8 条原始独立人工上下文留作后续研究（当前不用于校准；校准来自 E8 干净校准指令）。同一个候选词组跨样本复用参考插入结果，避免浪费 GPU；重复结果不视为独立触发器证据。

**计算预算：** 400 条全量输出，最多 256 个玩家/条；先做全单词、全连续二/三词，再做 12 种子稀疏二阶图；最后每条最多 4 个反事实候选。程序不会偷偷缩减 400 条到 20 条，但对不可安全处理的指令会输出 `skipped` 和原因。默认不生成回答文本，因此不能据此宣称 400 条样本的攻击成功率。GPU 训练和参数更新均禁用。

## 科学限制与未来验证

1. **当前 400 条仍是 BadNet 单词触发器的既有数据**，无法单凭该实验宣称真正的两词或三词后门已被发现。需要未来独立的合成/真实组合触发器攻击数据进行验证。
2. 连续 2/3 词窗口可以捕捉某些纯组合激活，但非连续三词不保证穷举；图通道只分析部分种子节点。超长的多词触发器（4+ 词）仍不在这轮范围。
3. E8 的 `top1_gap` 与 E8 heldout 标签只作为冻结对照及报告，E12 搜索在 GPU 推理时不读取标签；不在同批 heldout 上拟合融合阈值或汇报新测试 F1。
4. 二、三阶 Harsanyi 反映的是**固定价值函数的非加性**，不等于在模型语义/输出层证明交互因果；反事实匹配控制也不可能消除所有文本扰动因素。
5. 数据中重复出现同一候选词组时，插入方向可能复用，统计样本独立性有限。小样本经验零分布与长度差异限制校准解释。
