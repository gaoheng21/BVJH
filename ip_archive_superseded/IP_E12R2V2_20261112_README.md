# InteractionPrism E12R2V2 — 全量样本检测结果可视化修正版（CPU）

本包是 **E12R2 的修订交付版本**，采用新文件名和新输出目录，不覆盖原版 E12R2、E12R1 或冻结的 E8R1。它只读取 **E12R1 已经算好的 400 条 JSONL**，不需要重新运行 A100，不加载模型，也不修改任何检测规则。

## 为什么上版没有“检测结果”？

原版 E12R2 是离线交互审计，默认打印各组汇总和 20 条漏检的机制分析；没有专门打印 **400 条样本的真实标签与 E8 后门/正常判定**。本版已补齐。

**特别区分两类结果：**

- `e8_detected_as`：E8R1 **冻结的正式二分类**，`BACKDOOR` 或 `CLEAN`，来源于 E12R1 存档的 `e8_prediction`，不是新算的标签拟合。
- `e12_detection_verdict=NOT_DEFINED`：E12R1 的可变规模搜索及反事实验证目前仍是探索性机制分析，**没有经过独立校准的二阶段二分类阈值**。E12 的联盟规模、Harsanyi 值、干净校准 z、方向对齐等是证据，不能擅自显示为正式新检测结果、F1 或 ASR。
- `true_label` 与 `TP/FP/FN/TN` 仅用于离线评价；E12 原始搜索并未使用测试标签或已知触发器。

## 一条命令运行（CPU，不需要 A100）

将 ZIP 上传到 `/science/gh/Backdoor-Vaccine` 后：

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E12R2V2_20261112_detection_display_package.zip
bash IP_E12R2V2_20261112_run.sh
```

要求同目录已有一次 **成功完成** 的 E12R1，例如：
`outputs/interactionprism/e12_runs/E12R1_20261112_031332_3464936_31849/all_400_variable_coalitions.jsonl`。

默认自动选择最新且有 `summary.json` 的 E12R1 目录。也可指定准确输入：

```bash
E12_SOURCE_JSONL='outputs/interactionprism/e12_runs/E12R1_20261112_031332_3464936_31849/all_400_variable_coalitions.jsonl' bash IP_E12R2V2_20261112_run.sh
```

程序会严格核验 400 条、原编号、200/200 真实标签、每行 E8 结果与 TP/FP/FN/TN 的一致性，并在可核验的情况下核查 E8 分数是否符合冻结阈值。

## 终端会显示什么？

1. **冻结 E8 混淆矩阵**：TP、FP、FN、TN；Precision、Recall、F1、FPR。
2. **400 条逐样本检测结果**，每行 `id, truth, E8=BACKDOOR/CLEAN, TP/FP/FN/TN, E8_score, winning_word, E12_global_phrase, size, signed I, calibration z, alignment`。注意全局候选可能没有被挑入四个反事实验证名额，此时其 `stage2_align=NA`，不是模型证据为零。
3. **易复制的 COPY_TO_CHATGPT 区块**：全局指标、TP/FP/FN/TN 分组的交互统计，以及 **20 条 FN 和 4 条 FP** 的逐样本简述与输出文件路径。

示意行（仅展示格式，数值以实际运行输出为准）：

```
id=010 truth=POISON E8=CLEAN [FN] score=... e8_word='...' | E12_global='...' (size=3, I=..., z=..., stage2_align=...) | E12_selected='...' (align=...)
```

## 输出文件（新建独立目录）

`outputs/interactionprism/e12_audits/E12R2V2_.../`

| 文件 | 作用 |
|---|---|
| `sample_level_detection_400.csv` | **全部 400 条的真实标签、E8 判定和 E12 异常交互证据**，包含原始指令、冻结 E8 Top-6、全局排名第一联盟、已验证候选、二/三阶最大绝对贡献及状态 |
| `poisoned_200_detection_results.csv` | **单独 200 条中毒样本**，含 E8 的 TP/FN 和所有 E12 机制指标 |
| `clean_200_detection_results.csv` | 单独 200 条干净样本，含 E8 的 FP/TN |
| `E8_error_24_detection_results.csv` | 20 条 FN + 4 条 FP 的详细机制证据 |
| `E8_predicted_backdoor_samples.csv` | **冻结 E8 检测为后门**的全部样本（本次历史数据应为 184 条，含 4 FP） |
| `E8_predicted_clean_samples.csv` | **冻结 E8 检测为正常**的全部样本（本次历史数据应为 216 条，含 20 FN） |
| `terminal_400_results.txt` | 终端打印的 400 条简表，可反复 `cat` 查看 |
| `copy_to_chatgpt.txt` | 最后回传给 ChatGPT 的摘要、20 FN + 4 FP、文件路径 |
| `all_400_sample_audit.csv` | 原 E12R2 的逐样本离线审计字段 |
| `poisoned_200_sample_audit.csv` | 原 E12R2 的中毒样本审计 |
| `FN_20_sample_audit.csv` | FN 的联盟结构及消融 |
| `all_valid_multiword_finalists.csv` | 多词联盟反事实细节 |
| `summary.json` | 统计与输入 SHA-256 |

## 运行完没有复制？

```bash
cd /science/gh/Backdoor-Vaccine
RUN_DIR=$(ls -td outputs/interactionprism/e12_audits/E12R2V2_* | head -n 1)
cat "$RUN_DIR/copy_to_chatgpt.txt"       # 总体 + 20 FN/4 FP
cat "$RUN_DIR/terminal_400_results.txt" # 400 条逐样本检测显示
```

**注意：** 数据仍是 BadNet 已知单词触发器的测试集，不代表已经验证未知多词组合后门。当前 E12 没有正式二分类指标，不应将这次“显示修正”描述为新检测算法或新准确率。
