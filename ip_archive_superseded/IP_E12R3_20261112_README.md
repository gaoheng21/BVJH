# E12R3 — Label-blind, disjoint-clean-calibrated second-stage rule (A100)

## Objective

A true binary decision is defined **in advance**, using the E12R1 automatic coalition discovery results and same-model stage-2 counterfactual evidence. It is NOT a replacement for E8R1, which remains completely frozen.

Source: E12R1 successful 400-row JSONL and 48 clean examples used by the E12R1 search family null. The **other 352 prompts** from original E8 clean_cal `train_clean[100:500]` form a *disjoint* score-threshold calibration set. All 352 are reprocessed with the same E12R1 code and parameters using one A100; the existing 400 E12R1 forward passes are not rerun.

**Frozen score definition** for every input x:

    score(x) = max_{S in up to 4 E12R1 finalist coalitions}
                   ( median_cos(Delta_x(S), insert_delta(S))
                   - median_cos(Delta_x(S), insert_delta(neutral_S)) )

Scores are missing when no finalist can be evaluated; missing calibration scores are conservatively imputed as +infinity, while missing test scores are never flagged as positives. No trigger, target string or sample ground-truth label enters the score.

**Predeclared FPR calibration:** alpha=0.02, n=352, `k=ceil((n+1)*(1-alpha))=346`. Use the k-th *ascending* calibration score as the threshold, with the strict `score > cutoff` rule. This is an exploratory calibration for the stage-2 score alone, assuming comparable clean distributions. The E8 OR E12R3 union does **not** inherit the same 2% FPR guarantee.

Outputs: calibrated E12R3 predictions, original E8 predictions and exploratory OR predictions, each with confusion matrix, precision/recall/F1/FPR computed using heldout labels **only after all predictions have been frozen**.

**Critical limit:** This is NOT a pristine independent detection benchmark. Although calibration is disjoint and label-blind, the E12R3 feature was selected after previous research on the SAME 400 E8 heldout samples. Its metrics must be called *exploratory reused-heldout metrics*, not unbiased independent test F1. A completely new labeled test set and preferably an actual multiword-trigger attack model are needed for confirmatory claims.

## Run

In your existing `BV` conda environment, in `/science/gh/Backdoor-Vaccine` with the original E12R1 package files present:

```bash
unzip -n IP_E12R3_20261112_independent_clean_calibration_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E12R3_20261112_run.sh
```

Default runs ALL 352 remaining clean calibration prompts, with exactly the parameters recorded in your successful E12R1 run. This may require a substantial A100 run. Do not start additional concurrent jobs. The program prints progress every 10, and saves each result as it is computed.

After an interruption, use the exact run directory from `outputs/interactionprism/e12_runs/E12R3_*`, e.g.:

```bash
E12R3_RESUME_RUN=outputs/interactionprism/e12_runs/E12R3_YOUR_RUN_ID CUDA_VISIBLE_DEVICES=0 bash IP_E12R3_20261112_run.sh
```

For manually choosing another historical E12R1 run: `E12R1_RUN=outputs/interactionprism/e12_runs/E12R1_YOUR_RUN_ID`.

## Methodological safeguards

- E8R1, E11 and E12R1 never overwritten; both frozen package and raw-data hashes checked.
- The original 48 E12R1 clean-search calibration samples are excluded from the 352 E12R3 score calibration samples.
- No recalibration of the E8 threshold or tuning on E12R1 heldout labels.
- The candidate-search score uses E12R1's own clean-family maxima; the secondary score is calibrated as a **per-input maximum over shortlisted candidates**, controlling selection within each clean calibration sample.
- Empirical 2% FPR is a clean-calibration design target for E12R3 alone, not a promise for real-world distribution shifts.
- No unknown trigger or target behavior is hardcoded.
- Actual multiword triggers require a separate challenge dataset; single-word BadMagic does not establish multiword trigger generalization.
