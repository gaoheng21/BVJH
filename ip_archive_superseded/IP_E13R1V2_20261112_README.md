# InteractionPrism — E13R1V2 行为解释（**无小模型；只看 E12R3**）

## 核心原则

**E12R3 是唯一的中毒判定来源。** 不使用 E8 投票、不使用中毒标签筛选、不加载 Qwen 或其他小模型，也不修改 E12R3 的任何预测。E13R1V2 仅作为后续行为解释实验，**不计算新的检测 F1/FPR**。

- E12R3=0：立即跳过行为生成，保留在 400 条总表。
- E12R3=1：读取 E12R1 已确定的最高反事实候选联盟，使用原 BV 后门模型验证它诱导的实际回答。
- 如果没有合法候选：单独标记 `NO_VALID_CANDIDATE`，不强行编造解释。
- 如果输出不形成跨任务一致的固定异常回答：标记未解释，**不能说它是正常，也不能说已找到后门目标**。

历史 E12R3 结果为 205 阳性、195 阴性（仅供预期核对；实际运行以读取的冻结结果为准）。默认只对 E12R3 阳性进行生成。没有 Qwen，也不依赖 `/science/llms/`。

## 运行（一张 A100）

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E13R1V2_20261112_rule_only_package.zip
CUDA_VISIBLE_DEVICES=0 bash IP_E13R1V2_20261112_run.sh
```

环境沿用已有 BV、torch、transformers、peft；需要之前 E12R1 包中的 `IP_E12R1_20261112_contexts.json`，以及 E12R1/E12R3 已完成的运行目录。模型位置直接读取 E12R1 manifest，不需要额外指定，不需要修改冻结目录。

先做小批量（仅前 15 个 E12R3 阳性；另起独立运行目录）：

```bash
E13_MAX_CASES=15 CUDA_VISIBLE_DEVICES=0 bash IP_E13R1V2_20261112_run.sh
```

**处理步骤：**
1. 输入 E12R3 的检测结果、E12R1 的异常联盟及一至三阶交互值。只使用 E12R3 预测做筛选。
2. 对每个 E12 阳性：生成原文回答、删除候选后的回答；再在四条参考任务中生成原任务和插入候选的配对回答。
3. 使用前两条任务发现是否存在相同的固定异常回答；另两条任务验证它是否重现，及正常、普通词和中性词对照是否不会重现。
4. 仅对成功验证的多词联盟再生成全部真子集，使用行为命中率计算对应 Harsanyi 交互值，并检查是否完整联盟才触发。
5. 用确定性规则记录发现的**具体回答**、是否删词后消失、行为交互值以及未能解释的情况；无额外 LLM 或模型评审。

**限制：** 此版擅长识别固定输出劫持，对于同一后门诱导不同语义回答的行为可能输出 `NOT_FOUND`/`UNCONFIRMED_FIXED_PATTERN`；必须据实报告，不能称其已经覆盖所有攻击目标。原有 400 heldout 多次用于机制研究，不是新的独立测试。真实多词共同触发器尚需单独数据验证。

## 独立输出

`outputs/interactionprism/e13_runs/E13R1V2_*`：
- `all_400_behavior_report.csv`：400 条（包括跳过的 195 条阴性）
- `poisoned_200_behavior_report.csv`、`clean_200_behavior_report.csv`：离线按标签审计，不参与路由
- `behavior_explained_cases.csv`：严格验证的固定行为案例
- `sample_behavior_partial.jsonl`、`generation_cache.jsonl`：逐条持久化、断点续跑
- `terminal_400_results.txt`、`report.md`、`summary.json`
- `copy_to_chatgpt.txt`：可直接复制的压缩汇总

输出包含原始交互贡献、候选、真实配对回答、行为固定签名、删除后的恢复情况、行为 Harsanyi 值、GPU 生成数量和计时。

重新查看复制块：
```bash
cd /science/gh/Backdoor-Vaccine
RUN_DIR=$(ls -td outputs/interactionprism/e13_runs/E13R1V2_* | head -n 1)
cat "$RUN_DIR/copy_to_chatgpt.txt"
```

断点续跑同一运行目录（参数与首次运行一致）：
```bash
E13_RESUME_RUN=outputs/interactionprism/e13_runs/E13R1V2_你的目录名 CUDA_VISIBLE_DEVICES=0 bash IP_E13R1V2_20261112_run.sh
```

可选参数：`E13_MAX_CASES=0`（默认全部阳性）、`E13_MAX_NEW_TOKENS=48`、`E13_PROGRESS_EVERY=10`，可通过 `E13_E12R3_RUN` 固定具体 E12R3 运行目录。

CPU 测试：`python IP_E13R1V2_20261112_tests.py`，GPU 尚未实测。
