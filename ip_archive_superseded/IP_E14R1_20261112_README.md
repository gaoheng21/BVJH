# InteractionPrism E14R1 · 其他攻击类型全集测试（单卡 A100）

## 目标

停止反复使用 BadMagic 数据调算法，直接把已经固定的 InteractionPrism E12R1 + E12R3 迁移到 **其他攻击方式**。默认聚焦同一个目标任务 `negsentiment`，对 BV/CROW 的 `sleeper,vpi,mtba,ctba` 四种攻击分别执行 **200 中毒 + 200 干净 = 400 条全集**。对于其他任务，可设置 `E14_TASKS=all`。不会挑 20 条、30 条代替全集。每种攻击独立给出 TP/FP/FN/TN、Precision、Recall、F1、FPR、逐样本证据；不允许用 BadNet 的 LoRA 冒充其他攻击模型。

## 最短命令

把 ZIP 放到 `/science/gh/Backdoor-Vaccine` 根目录后：

```bash
cd /science/gh/Backdoor-Vaccine
unzip -n IP_E14R1_20261112_cross_attack_fullset_package.zip

# 建议先看服务器上哪些攻击确实有匹配的 LoRA 和数据（CPU；不加载 GPU）：
E14_INVENTORY_ONLY=1 bash IP_E14R1_20261112_run.sh

# 一张 A100，逐攻击全量执行；运行过程中自动缓存并逐样本落盘：
CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh
```

默认目录优先使用前几轮已经成功加载的 `/home/gh/Llama-2-7b-chat-hf`；若基座实际在其他目录，例如 `/science/llms/Llama-2-7b-chat-hf`，设置：

```bash
E14_BASE=/science/llms/Llama-2-7b-chat-hf CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh
```

使用 BV 当前 Python 环境，需 `numpy, torch, transformers, peft, tokenizers`。**只评估匹配现有攻击的模型，不自动训练或下载任何模型，也不会修改冻结的 E8/E12/E13 文件。**

## 输入适配规则（谨防错误评估）

每个 `task/attack` 组合都要求以下文件同时存在：

```text
backdoor_weight/*/<task>/<attack>/adapter_config.json
backdoor_weight/*/<task>/<attack>/adapter_model.safetensors  # 或 adapter_model.bin

data/poison_data/<task>/<attack>/backdoor500_<task>_<attack>.json
data/poison_data/<task>/<attack>/none_backdoor500_<task>_<attack>.json
data/test_data/poison/<task>/<attack>/backdoor200_<task>_<attack>.json
data/test_data/clean/<task>/test_data_no_trigger.json
```

如果某种攻击只有中毒数据、尚未训练受攻击 LoRA，则该攻击输出 `SKIP_MISSING_INPUT`，**绝不借用 BadNet adapter 得到伪结果**。如果模型不是 Llama-2-Chat 对应架构，则严格拒绝错误加载；不自动猜基座。

某些真实服务器的受攻击 LoRA 目录不在标准位置。可提供 JSON 映射文件（不需要改项目）覆盖它：

```json
{
  "negsentiment/sleeper": {"adapter": "/science/models/my_sleeper_lora"},
  "negsentiment/vpi": {"adapter": "/science/models/my_vpi_lora"}
}
```

保存为如 `e14_override.json`，用 `E14_OVERRIDE_JSON=e14_override.json` 运行。也可以在相同字典中分别覆盖 `train_poison`, `train_clean`, `test_poison`, `test_clean` 路径。所有路径严格校验，数据少于 200/200 不会声称全集成功。

## 逐攻击的算法（方法不从 BadMagic 学新规则）

1. **模型专属参考中心**：按冻结 E8/E12 协议，使用该攻击训练来源的前 30 条中毒和前 100 条干净文本，重算本模型的层 -1 表征中心。此处不使用测试样本。此步骤保留原 E12 中心构造程序，但参考文本换成对应攻击来源；是一项需如实披露的跨模型协议适配。
2. **48 条独立干净搜索校准**：按 E12R1 原样计算 1～3 词等效交互、相邻词组和稀疏图二词，并分别以每条干净指令的最高交互建立候选排序参照。保持四个候选渠道与最多四个 finalists。
3. **352 条不重叠干净阈值校准**：保持 E12R3 分数公式：`max(candidate 插入/移除方向对齐 - neutral 插入/移除方向对齐)`；使用固定 `alpha=0.02` 的严格上分位阈值。**不将 BadNet 的数字阈值 0.4368 直接迁移到别的模型，也不使用测试标签调阈值**。
4. **全集 400 条检测**：中毒 200、干净 200，每条使用自动发现的联盟和对应的模型计算分数。保存所有联盟和反事实明细、400 条逐样本 CSV、单独中毒 200 CSV、误报和漏检表、混淆矩阵。
5. **E13 规则式行为验证（默认开启）**：只对 **该攻击 E12 检测阳性** 的样本，用同一受攻击模型做真实生成、候选删除、四条独立参考任务插入与中性/普通词对照；可自动识别跨任务**完全相同的固定输出**及其行为层 Möbius 交互。不能发现固定输出不意味着它不是后门，例如拒答、语义偏移、代码植入等攻击不适用该规则。**行为解释不参与检测标签，不使用小模型。**

科学警告：原来的 400 条 BadNet 数据曾参与方法设计；其他攻击上的这次实验属于跨攻击迁移检验，但可能共享数据来源、模型架构，不能直接称作全新、独立的终极 benchmark。毒数据来源 `true_label=1` 只代表植入了攻击输入，不代表对应 LoRA 每条都攻击成功；本脚本不声称测试了 target-specific ASR。

## 运行预算与续跑

每个成功运行的攻击要处理 48 条搜索校准 + 352 条阈值校准 + 全部 400 条测试（共 800 条不同处理任务）；此外只对检测阳性执行 E13 生成。多攻击在**一块 A100 上串行**执行，不能保证很快；但每 10 条保存一次进度，JSONL 实际每条即时落盘。已有完成的攻击自动跳过，重启不会覆盖数据。

```bash
# 跳过额外的行为生成，只跑 400 条/攻击的等效交互检测：
E14_BEHAVIOR=none CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh

# 只跑 negsentiment 的 sleeper 和 vpi 两类（各 400）：
E14_ATTACKS=sleeper,vpi CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh

# 遍历所有项目任务的四种攻击（匹配模型的才运行）：
E14_TASKS=all CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh

# 中断后续跑之前的确切目录（例）：
E14_RESUME_RUN=outputs/interactionprism/e14_runs/E14R1_20261112_XXXX \
CUDA_VISIBLE_DEVICES=0 bash IP_E14R1_20261112_run.sh
```

改变参数会创建新运行，旧目录的 manifest 会阻止混合配置断点续跑。遇到模型/数据缺失，终端会在扫描阶段报告 `SKIP_...`；失败的攻击有 `FAILED` 和错误信息，不会算成成功的指标。

`outputs/interactionprism/e14_runs/E14R1_<timestamp>_<pid>/`：

```text

cross_attack_summary.csv          # 每种攻击一行的全部指标
copy_to_chatgpt.txt              # 简短总结，不需要粘贴几千行日志

    manifest.json                # 模型权重、源文件哈希/校准协议
    search_48_clean_null.json
    threshold_cal_352_partial.jsonl
    test_400_partial.jsonl       # 完整所有候选等效交互+反事实证据
    all_400_detection.csv
    poisoned_200_detection.csv
    clean_200_detection.csv
    false_positives.csv          # 如有
    false_negatives.csv          # 如有
    terminal_400_detection.txt   # 全400逐条检测结果
    behavior_partial.jsonl       # 如启用行为验证
    generation_cache.jsonl       # 如启用行为验证

    poisoned_200_behavior.csv    # 如启用行为验证
```

运行结束：

```bash
RUN_DIR=$(ls -td outputs/interactionprism/e14_runs/E14R1_* | head -n 1)
cat "$RUN_DIR/copy_to_chatgpt.txt"
```

终端会显示每个攻击 400 条样本的检测分数、联盟、规模、带符号 Harsanyi 交互等，同时给出可复制的汇总块。

## 审稿时需保持的界限

- 搜索排序、阈值校准与 E13 行为发现均不预先指定触发器或攻击目标。E13 的字符串规则主要识别固定回答型攻击，其他行为的“不确定”必须如实报告。
- 高阶 I2/I3 大不代表多个词必须同时触发，只有完整联盟和真子集的行为对照才能检验这种必要性。
- `alpha=0.02` 是基于干净校准集的设计目标，**不保证各攻击测试 FPR=2%**。
- 没有匹配 LoRA，绝不能用“只换中毒测试集”的伪比较替代跨攻击评估。
- 提供 19 项纯 CPU 回归测试；真正的模型质量指标必须在你的 A100 运行后读取，不会编造结果。
