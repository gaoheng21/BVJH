## 1. 量定义（全部来自冻结代码）

### 1.1 Keep-only 价值（E8 `_measure_v_fixed_tail` 语义，逐字沿用）

```
v(S) = 1 − cos( h(x_S) − h̄ , h(x) − h̄ )
```

- `x_S`：把可替换区内**非**联盟 S 的每个词替换为中性填充 ` thing`（子词片段删除），
  联盟词保留；公共读出尾巴附加在所有变体之后（raw 协议尾巴为空）。
- `h(·)`：最后位置隐状态（`hidden_layer=-1`，E8 `_forward`）。
- `h̄`：**同协议**下 100 条干净指令（`test_data_no_trigger.json` 前 100）最后位置隐状态的均值
  （与 E20 clean-center 同构造；用测试侧干净集是声明过的偏差，防御侧干净指令等价）。

**声明偏差（唯一实现改动）**：alpaca 协议下模板词不属于可替换区——中性填充只作用于
Instruction 段内（用字符 span 界定），模板其余部分原样保留。价值公式不变。
理由：`_measure_v_fixed_tail` 的全序列替换会把模板词一起填掉，破坏协议本身。


## 4.5 修正案（2026-11-20，聚合前冻结；仅 badnet:0 的 6 行原始 v 在调试中可见，未做任何聚合）

v 是余弦**距离**（越小 = 越对齐原读出方向），触发贡献的正确量为
`Δ(S) = v(∅) − v(S)`（正值 = 保留 S 把隐状态拉回原始方向）。§3 指标改在 Δ 上定义：

| 维度 | 修正公式 |
|---|---|
| 载体 | C = `max_i Δ({u_i}) / Δ(U)` |
| 组合性 | A_ij = `I_Δ({u_i,u_j}) / Δ(U)`（Harsanyi 股息对 v(∅) 平移不变，E8 `_harsanyi` 原样可用） |
| 位置 | P = `Δ_mid / Δ_prefix`（另报 suffix） |
| 协议 | R = `Δ(U)@proto / Δ(U)@raw` |

Δ(U) ≤ 1e-4 时比值记 NaN 并报原始 Δ。判据（§4）不变，全部改读 Δ 口径。

## 5. 边界

- v 为余弦距离，值域 [0,2]；分母 |v|<1e-6 时比值记 NaN 并报原始值。
- 本实验只测价值函数层，不产生新检测器/阈值，不回流任何冻结结论。
- fp16 / batch 16 / max_len 512；tokenizer `use_fast=True`——与冻结**测量**管线（E12R1/E12R3/E20，
  offset mapping 所需）一致；`use_fast=False` 仅是 E13/E14R2 生成臂的约定，本实验无生成臂。
